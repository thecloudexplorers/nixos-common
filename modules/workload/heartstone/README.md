# heartstone

Kanidm identity provider (container `heartstone-1`), served at `idm.raboes28.nl`.

## Handy commands

Run on the host. See [docs/kanidm-install.md](../../../docs/kanidm-install.md)
and [docs/nextcloud-kanidm-sso.md](../../../docs/nextcloud-kanidm-sso.md) for
the full procedures.

```bash
# Shell / logs
sudo nixos-container root-login heartstone-1
sudo nixos-container run heartstone-1 -- journalctl -u kanidm.service -f
sudo nixos-container run heartstone-1 -- systemctl status kanidm

# Admin login (CLI client is installed in the container)
sudo nixos-container run heartstone-1 -- kanidm login --name idm_admin --url https://idm.raboes28.nl

# Inspect identities
sudo nixos-container run heartstone-1 -- kanidm person list --name idm_admin
sudo nixos-container run heartstone-1 -- kanidm group list --name idm_admin
sudo nixos-container run heartstone-1 -- kanidm group get nextcloud-users --name idm_admin

# Generate a credential reset link for a user
sudo nixos-container run heartstone-1 -- kanidm person credential create-reset-token <user> --name idm_admin

# Nextcloud OAuth2 client secret (used by dalaran's user_oidc)
sudo nixos-container run heartstone-1 -- kanidm system oauth2 show-basic-secret nextcloud --name idm_admin

# Check the served certificate
echo | openssl s_client -connect idm.raboes28.nl:443 -servername idm.raboes28.nl 2>/dev/null | openssl x509 -noout -dates -subject

# Backups (online backups, 5 versions kept)
ls -la /mnt/zdata/heartstone/1/backups

# Container lifecycle (avoid unless recovering)
sudo nixos-container restart heartstone-1
```

## What runs here

- **Kanidm 1.11** server ([service-kanidm.nix](service-kanidm.nix)) with
  declarative provisioning of groups, persons and the `nextcloud` OAuth2 client.
  Add or change identities in that file and rebuild.
- Groups: `faml-users`, `kids-users`, `test-users`, `nextcloud-users`
  (only members can sign in to Nextcloud).
- Online backups with the last 5 versions kept.

## Dependencies

| Dependency | Purpose                                                    |
| ---------- | ---------------------------------------------------------- |
| `medivh`   | Issues the `idm.raboes28.nl` certificate (read-only mount) |
| `baleroc`  | Public reverse proxy                                       |
| `dalaran`  | OIDC client                                                |

## Persistent data (host bind mounts)

- `/mnt/ssd/heartstone/1/var/lib/kanidm` holds the database and secrets.
- `/mnt/zdata/heartstone/1/backups` holds the backups.
- `/mnt/ssd/heartstone/var/lib/acme/idm.raboes28.nl` holds the certificate (read-only).

## Notes

The OAuth2 client secret is generated by Kanidm and is not declared in Nix. After
it is regenerated, update the secret file mounted into `dalaran-1`.
